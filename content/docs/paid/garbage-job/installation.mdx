# Advanced Garbage Job - Installation

This will go over the installation guide for scfd_garbagejob. Please be sure to read this carefully and if you have any questions, feel free to ask in our Discord.

<Steps>

<Step>
    ### Install & setup all dependencies

    - [ox_lib](https://github.com/overextended/ox_lib/releases/latest)
    - [ox_target](https://github.com/overextended/ox_target/releases/latest)
    - Make sure your server artifacts version is `29000` or above. Downloaded the [Windows](https://runtime.fivem.net/artifacts/fivem/build_server_windows/master/) or [Linux](https://runtime.fivem.net/artifacts/fivem/build_proot_linux/master/) artifacts.
    - Make sure your game build is set to 3095 or higher. See how to set your gamebuild [here](https://forum.cfx.re/t/tutorial-forcing-gamebuilds-on-fivem/4784977).
    - Make sure your server is running OneSync (Formally Onesync Infinity) and **not** legacy. See how to enable onesync [here](https://forum.cfx.re/t/onesync-infinity-how-to-use-it/996612).
</Step>
<Step>
    ### Install optional dependencies
    - [scfd_garbagejob_vehicles](https://github.com/scuffedlabs/scfd_garbagejob_vehicles/) - These are optional, however some of the preconfigured vehicles & features will not work without it.
    - [ox_inventory](https://github.com/overextended/ox_inventory/releases/latest) - This is optional, however some features will not work without it.
</Step>
<Step>
    ### Download the latest release from [CFX Portal](https://portal.cfx.re)
</Step>
<Step>
    ### Add the resources to your server.cfg (or resources.cfg)
</Step>
<Step>
```bash
start ox_lib
start framework # the name of your framework (i.e. ND_Core, es_extended, qbx_core). This is not necessary if you are using standalone.
start ox_target
start ox_inventory # Optional
start scfd_garbagejob_vehicles # Optional
start scfd_garbagejob
```
</Step>
</Steps>
